# reparatiielectronice.ro — site static Astro

Site reconstruit în Astro. Deploy: Cloudflare Pages (preset Astro, build `npm run build`, output `dist`).

- Date contact: `src/data/site.ts`
- Formular: înlocuiește `PUNE_CHEIA_WEB3FORMS_AICI` din `src/pages/contact.astro` cu cheia gratuită de la web3forms.com
- Redirecturi: `public/_redirects`
